# sasanka-web
A typing page for the Sasanka layout in Bengali. The sasanka keymapping algorithm, initially published in an ibus-table format ([see here](https://anamitro.github.io/ibus-table-sasankadeva)), had been designed for a fast and intuitive input engine, with a fixed layout highly conforming to custom phonetic conventions. You may see the actual algorithm [here]().
